# VoiceStack Atlas Knowledge Base purpose
Help an independent developer plan faster-whisper deployment from public source documentation. Reconcile CUDA/cuDNN/CTranslate2 compatibility with the correct documentation era, distinguish file decoding from already-decoded array inputs, and explain lazy generator execution. Cite the pinned original sources. Never infer benchmarking results or claim a GPU setup was executed.

Standing instruction: fw-current is the current snapshot; fw-v1 is historical. A historical CUDA 11/cuDNN 8 requirement and a current cuDNN 9 requirement are version-scoped facts, not interchangeable instructions. Always preserve the version context. If input parameters have no supported rule, request the missing facts rather than inventing a combination.

Source budget: four pinned upstream documents plus original structured compatibility rules. This is below the beta document budget. The schema separates conditions, claim, action, status and source references so comparisons are relational rather than keyword matching.
