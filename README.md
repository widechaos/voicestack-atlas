# VoiceStack Atlas

A version-aware faster-whisper deployment assistant for the Sanity Challenge, Path One. I built it to prevent one deceptively common mistake: combining a current installation guide with a historical GPU requirement and getting a plausible but unusable runtime.

**Status:** local implementation tested; Sanity project and Knowledge Base created; ingestion and live MCP verification in progress. This is not yet a submitted challenge entry.

## What is structured

Each original compatibility rule separates `when` (device, CUDA, cuDNN, input), `status` (current/historical), `claim`, `action`, and an evidence literal from a commit-pinned upstream source. The local preview applies those conditions deterministically. Historical facts remain visible, but cannot silently replace current rules. Unknown combinations produce a request for missing evidence.

The live agent uses Codex CLI connected directly to Sanity Context. It first reads `initial_context`, then retrieves relevant `knowledge_base_read` entries, or explores schema and queries GROQ. Every decision must cite an allowlisted original pinned source. A run is accepted as live only if its event stream contains successful Sanity orientation and retrieval calls.

## Run

Node 22+ is required.

```sh
npm ci
npm test
npm run validate
npm start
```

Open http://127.0.0.1:4317 for the **offline structured preview**. It does not silently impersonate live MCP. `npm run demo` prints the same decision trace for CUDA 12 / cuDNN 8 / array input.

For a real agent run, install and sign in to a supported Codex CLI. Provide a **personal** Sanity organization token with only Context Viewer permission in your local environment; do not commit it. The endpoint must be backed by the Knowledge Base. No model API key is required when using an existing eligible Codex sign-in; account usage limits still apply.

```sh
export SANITY_CONTEXT_URL=https://api.sanity.io/v1/context/organizations/omhwn8x7r/mcp/voicestack-atlas
# Set SANITY_ORGANIZATION_TOKEN in your shell without publishing it.
npm run probe
npm run agent -- 'I have CUDA 12, cuDNN 8 and 8kHz PCM audio as a NumPy array. What must I change before faster-whisper transcription?'
```

The runner ignores unrelated user MCP configuration, runs with a read-only sandbox, and uses an ephemeral session. Local evidence goes to ignored `runs/`. Review evidence before making it public. The source URL guard enforces citation membership, not semantic entailment; human review remains necessary.

## Evaluation

The test suite covers current versus historical requirements, two distinct compatibility pins, an unknown GPU combination, missing versions, raw arrays versus file decoding, CPU separation, malformed profile input, and unrecognized/missing citations. Evidence validation checks every rule's literal against the pinned file. These checks do not establish GPU installation success, ASR quality, or live Sanity availability.
